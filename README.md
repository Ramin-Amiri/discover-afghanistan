# Discover Afghanistan 🇦🇫

A minimal desktop application built with PySide6 and Qt Designer.

This project allows users to explore information about different Afghan provinces including:

- Capital city
- Traditional food
- Population
- Short description

## Technologies Used

- Python
- PySide6
- Qt Designer

## Features

- Interactive province selection
- Minimal dark-themed UI
- Dynamic information display
- Beginner-friendly project structure

## How To Run

1. Install Python
2. Install requirements:

```bash
pip install -r requirements.txt
Run the application:
python main.py
