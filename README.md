# Discover Afghanistan 🇦🇫

A minimal desktop application built with PySide6 and Qt Designer that allows users to explore information about different Afghan provinces.

## Features

- Explore Afghan provinces
- View:
  - Capital city
  - Traditional food
  - Population
  - Short description
- Minimal dark-themed interface
- Beginner-friendly PySide6 project

## Technologies Used

- Python
- PySide6
- Qt Designer

## How To Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/discover-afghanistan.git
```

### 2. Open the project folder

```bash
cd discover-afghanistan
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python main.py
```
